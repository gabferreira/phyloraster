# Package index

## All functions

- [`arg.check()`](https://gabferreira.github.io/phyloraster/reference/arg.check.md)
  : Check for missing arguments in function call
- [`canape.rast()`](https://gabferreira.github.io/phyloraster/reference/canape.rast.md)
  : Classify Phylogenetic Endemism using rasters
- [`dataR`](https://gabferreira.github.io/phyloraster/reference/dataR.md)
  : Presence-absence of 33 Australian tree frogs (Rosauer 2017)
- [`delta.grid()`](https://gabferreira.github.io/phyloraster/reference/delta.grid.md)
  : Delta of Diversity Metrics
- [`df2rast()`](https://gabferreira.github.io/phyloraster/reference/df2rast.md)
  : Transform a data.frame to raster
- [`geo.phylo()`](https://gabferreira.github.io/phyloraster/reference/geo.phylo.md)
  : Calculate phylogenetic community metrics for raster data
- [`geo.phylo.ses()`](https://gabferreira.github.io/phyloraster/reference/geo.phylo.ses.md)
  : Calculate phylogenetic community metrics and their standardized
  effect sizes for raster data
- [`inv.range()`](https://gabferreira.github.io/phyloraster/reference/inv.range.md)
  : Calculate the inverse of range size
- [`load.data.rosauer()`](https://gabferreira.github.io/phyloraster/reference/load.data.rosauer.md)
  : Load an example dataset with presence-absence data of 33 tree frogs
  and a phylogenetic tree for this species
- [`phylo.pres()`](https://gabferreira.github.io/phyloraster/reference/phylo.pres.md)
  : Prepare rasters and phylogenetic tree to run community metrics
- [`range_size()`](https://gabferreira.github.io/phyloraster/reference/range_size.md)
  : Calculate range size for a set of species using a raster as input
- [`rast.ed()`](https://gabferreira.github.io/phyloraster/reference/rast.ed.md)
  : Calculate Evolutionary distinctiveness for raster data
- [`rast.ed.ses()`](https://gabferreira.github.io/phyloraster/reference/rast.ed.ses.md)
  : Standardized effect size for Evolutionary distinctiveness
- [`rast.pd()`](https://gabferreira.github.io/phyloraster/reference/rast.pd.md)
  : Calculate phylogenetic diversity for raster data
- [`rast.pd.ses()`](https://gabferreira.github.io/phyloraster/reference/rast.pd.ses.md)
  : Standardized effect size for Phylogenetic diversity
- [`rast.pe()`](https://gabferreira.github.io/phyloraster/reference/rast.pe.md)
  : Calculate phylogenetic endemism for raster data
- [`rast.pe.ses()`](https://gabferreira.github.io/phyloraster/reference/rast.pe.ses.md)
  : Standardized effect size for Phylogenetic endemism
- [`rast.sr()`](https://gabferreira.github.io/phyloraster/reference/rast.sr.md)
  : Calculate species richness for raster data
- [`rast.we()`](https://gabferreira.github.io/phyloraster/reference/rast.we.md)
  : Calculate weighted endemism for raster data
- [`rast.we.ses()`](https://gabferreira.github.io/phyloraster/reference/rast.we.ses.md)
  : Calculate weighted endemism standardized for species richness
- [`shp2rast()`](https://gabferreira.github.io/phyloraster/reference/shp2rast.md)
  : Rasterize shapefile
- [`species.ed()`](https://gabferreira.github.io/phyloraster/reference/species.ed.md)
  : Calculate Evolutionary distinctiveness for each species
- [`species.tip.length()`](https://gabferreira.github.io/phyloraster/reference/species.tip.length.md)
  : Compute species tip length
- [`tip.root.path()`](https://gabferreira.github.io/phyloraster/reference/tip.root.path.md)
  : Compute tree edge lengths and node paths from root to each tip
